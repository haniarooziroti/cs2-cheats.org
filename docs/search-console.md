# Search Console workflow (cs2-cheats.org)

1. Open [Google Search Console](https://search.google.com/search-console) and add the **domain** property for `cs2-cheats.org` if it is not already there.
2. Under **Sitemaps**, submit: `https://cs2-cheats.org/sitemap.xml`
3. After deploys, optional: run `npm run build` so IndexNow runs when `INDEXNOW_KEY` is set.

## Useful URL patterns

| Intent | Path |
|--------|------|
| Home / CS2 cheats overview | `/` |
| Product hub | `/products/cs2-cheats/` |
| Articles | `/blog/` |
| Forums | `/forum/` |
